# 更新说明：双人语音分离

日期：2026-10-10。项目：`E:\dsp\dsp_py`。

新增独立「双人语音分离」页：输入两个人同时说话的混合录音，输出「分离音轨1」「分离音轨2」。不需要提供某人的声纹，不命名或识别 A/B。原人声/伴奏、四轨音乐分离及其算法、模型选择、导出模块保留。

## 使用

1. 重新启动 `run_windows.bat`，切换右侧「双人语音分离」。
2. 导入混合录音，或点击「加载参考混合音频」。
3. 选择 CPU，点击「分离两路语音」。当前电脑已经下载模型并安装独立环境。
4. 分离完成后，点「听音轨1」「听音轨2」切换，使用播放/暂停、进度条、音量和静音/独奏。
5. 「导出两路音轨」保存原混合音及两路结果；「导出当前试听」保存当前选择/音量组合，可选 WAV 或 FLAC。

任务在独立子进程中执行，可取消并保留日志。成功结果存入 `results/speakers/时间戳_任务ID/`，包括 WAV、`result.json` 和 `worker.log`，可以从本页历史重新打开。

## 参考音频

目录：`samples/speaker_reference/`。

| 文件 | 内容 |
|---|---|
| `overlap_mix.wav` | 六秒双人混合参考，16 kHz、单声道 |
| `reference_1.wav` | 混合前的已知原始一路 |
| `reference_2.wav` | 混合前的已知原始另一路 |
| `separated_1.wav` | 实际模型输出的匿名音轨1 |
| `separated_2.wav` | 实际模型输出的匿名音轨2 |
| `reference.json` | 来源、源文件 SHA256、偏移、增益和混合方式 |
| `separation_result.json` | 参考样例分离结果及模型记录 |

参考由项目已有的 `samples/demo_speech.wav` 与 `samples/manba.wav` 各取最多四秒构造，第二路延后 0.3 秒，补静音至六秒；使用统一峰值保护，原始两路相加等于混合文件。原录音可能带有背景声。

这些原始两路只用于试听对照和客观评估，**没有作为分离模型输入**。模型只接收混合录音。分离音轨1/2不保证对应参考原音1/2；输出编号不代表真实身份。

`make_speaker_reference.py` 可重新生成原始参考与混合。预先分离的两条音轨是本次真实模型输出，不能把它们当成干净参考答案。

## 模型与处理方式

使用 [SpeechBrain SepFormer WSJ0-2Mix 模型](https://huggingface.co/speechbrain/sepformer-wsj02mix)，固定版本 `3a28263`，两路输出，原生 8 kHz、单声道。只下载推理所需的 YAML、encoder、decoder、masknet，约 113 MB。

双声道输入先取声道平均，再重采样至 8 kHz；结果恢复原文件采样率和样本数，但两条输出都是单声道。恢复采样率不会恢复模型没有保留的高频细节，因此不等于高保真录音。

长录音最多按八秒分块，重叠一秒，以重叠部分的波形相关性匹配匿名音轨，并交叉淡化。没有声纹注册或姓名识别。重叠处无有效语音时，无法保证跨块音轨编号始终对应同一人。

模型的 SI-SNR 训练不约束绝对输出增益和极性；对每块以原混合波形校准两路输出，避免超满幅的未经校准结果。校准系数记录在结果清单中。输出 WAV 为浮点格式；试听/混音导出可使用统一峰值保护。

## 独立运行环境与原功能保护

新增环境：`.venv-speakers`，Python 3.12、`torch/torchaudio 2.7.1+cpu`、`speechbrain 1.0.3`。原 `.venv` 的 PyTorch 2.14.1+cpu 与 pymss 2.1.7 保持原版本。

Windows 换电脑后运行 `setup_speakers_windows.bat`。它先安装匹配的 CPU PyTorch / torchaudio，再安装 `requirements-speakers.txt`。锁定清单为 `requirements-speakers-lock-win-py312.txt`。CUDA 需在独立环境中安装匹配的 CUDA 版，当前只实际验证 CPU。

可以拷贝源码、`models/speakers/` 与参考 WAV，在新电脑重新建立环境；本机 venv 不建议直接跨电脑复制。模型完整性标记为 `model_manifest.json`，下载支持续传和校验，取消后未完成的 `.part` 文件不作为完整模型。

`music_panel.py`、`music_worker.py`、`core/music.py`、`requirements-music.txt` 的前后 SHA256 一致。双人分离复用既有播放器/导出组件；仅在主界面增加新页及播放设备协调，避免两个工作区同时出声。音乐算法和模型缓存没有迁移到新环境。

## 实际验证

六秒参考在 CPU 上完成分离，worker 总耗时约六秒，包含缓存检查、加载、推理和保存。两条输出均为 96000 个样本、16 kHz。

在原始 16 kHz 参考上计算 SI-SDR，以最优两路排列匹配参考，仅用于验证，不是身份识别：

| 已知来源 | 混合输入 SI-SDR | 分离后 SI-SDR | 改善 |
|---|---:|---:|---:|
| 参考原音1 | -0.11 dB | 10.29 dB | +10.40 dB |
| 参考原音2 | -0.11 dB | 9.41 dB | +9.52 dB |

此案例说明算法确实分开了两路，不能推断任意录音同样有效。模型主要以英语混合语音训练；声音相似、噪声、混响、极小声的第二人以及三人以上说话可能出现串音、失真或漏分。

| 检查 | 结果 |
|---|---|
| 新增双人分离专项 | 14/14 通过 |
| 原有音乐分离、降噪和任务回归 | 28/28 通过 |
| 自动带阻回归 | 18/18 通过 |
| 混响/去混响回归 | 13/13 通过 |
| 默认及最小窗口布局 | 11/11 通过 |
| 两个环境的 pip check | 无依赖冲突 |

专项包含真实模型输出、参考质量、原始两路加和、跨块换序、48 kHz 双声道输入、原长度、真实进程取消、历史隔离、独奏/定位、导出、缺失环境提示和音乐源文件哈希保护。自动测试不播放扬声器，请用附带音频和本页试听检查听感。

证据目录：`results/verification_speakers_20261010/`，其中 `reference_quality.json`、`real_separation/result.json` 和各项日志保存实际结果。
