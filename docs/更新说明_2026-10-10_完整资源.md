# 完整资源上传说明

日期：2026-10-10。

按追加要求，将大模型、虚拟环境、训练数据和个人录音上传到同一个 GitHub 项目。

## 存放位置

个人录音在代码仓库的 `recordings/`，随 `git clone`、`git pull` 下载。

其他资源使用 [Releases 资源备份](https://github.com/KurolMato/dsp/releases/tag/assets-20261010)，分为四个 ZIP：

| 文件 | 内容 |
|---|---|
| `all-models.zip` | `models/` 中的全部模型（不含单独打包的噪声库），以及 `models_loo/`；含音乐、双人分离、DFN3、GTCRN、默认 MLP 和本机训练版本 |
| `training-noise-bank.zip` | `models/noise_bank/`，包括合成噪声、真实噪声数据、来源与许可说明 |
| `windows-main-venv-py312.zip` | 原电脑 `.venv/` 的完整 Windows Python 3.12 环境快照 |
| `windows-speakers-venv-py312.zip` | 原电脑 `.venv-speakers/` 的完整 Windows Python 3.12 环境快照 |

压缩包保留项目相对目录结构，解压位置应为项目根目录。音乐和双人分离的重复运行缓存、模型内 Python 字节码不重复打包；原始模型权重全部保留。

[GitHub 普通仓库](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github)限制大文件；[Release 附件](https://docs.github.com/en/repositories/releasing-projects-on-github/about-releases)单文件需小于 2 GiB。因此把几万项环境文件和大型数据放在 Release 附件中，代码仓库保持轻量。

Release 中同时提供 `assets-manifest.json` 和 `SHA256SUMS.txt`，记录每包的压缩大小、原始大小、文件数和 SHA256。打包后逐个验证 ZIP CRC，再上传并核对远端附件。

## 在另一台电脑恢复

1. 克隆代码仓库，进入 `dsp` 项目根目录。
2. 下载 `all-models.zip` 和 `training-noise-bank.zip`，解压到项目根目录，保留其中的 `models/` 和 `models_loo/` 层级。
3. 在新电脑安装 64 位 Python 3.12，运行 `setup_music_windows.bat`；需要双人分离时，再运行 `setup_speakers_windows.bat`。
4. 运行 `run_windows.bat`。

已下载对应模型时，界面会复用本机模型文件。个人录音已在 Git 仓库中，无需另外下载资源包。

两份虚拟环境 ZIP 是备份，不是跨电脑的免安装运行包。`pyvenv.cfg`、脚本和扩展保留原电脑的环境信息；复制到另一台电脑可能失效。若解压这些环境，启动脚本仍会检测，必要时保留失效环境并重建。新电脑通常直接按第 3 步安装即可，无需下载环境 ZIP。

可以用 PowerShell 校验下载文件：

```powershell
Get-FileHash .\all-models.zip -Algorithm SHA256
```

将结果与 `SHA256SUMS.txt` 中对应文件的值核对，再解压。
