# 模型、训练数据与录音上传说明

资源打包日期：2026-10-10。2026-10-11 按最新要求取消虚拟环境上传。

## 存放位置

个人录音在代码仓库的 `recordings/`，随 `git clone`、`git pull` 下载。

大型模型和训练数据存放在 [Releases 资源备份](https://github.com/KurolMato/dsp/releases/tag/assets-20261010)：

| 文件 | 内容 | 压缩大小 |
|---|---|---|
| `all-models.zip` | `models/` 中的全部模型（不含单独打包的噪声库）及 `models_loo/`；含音乐、双人分离、DFN3、GTCRN、默认 MLP 和本机训练版本 | 608.5 MB |
| `training-noise-bank.zip` | `models/noise_bank/`，包括合成噪声、真实噪声数据、来源与许可说明 | 1,051.5 MB |

另有 `assets-manifest.json` 和 `SHA256SUMS.txt`，记录每包的压缩大小、原始大小、文件数和 SHA256。两包共约 **1.66 GB**；原始模型和训练数据共约 **2.19 GB**。打包后验证完整 ZIP CRC，并核对 GitHub 返回的大小和 SHA256。

[GitHub 普通仓库](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github)限制大文件；[Release 附件](https://docs.github.com/en/repositories/releasing-projects-on-github/about-releases)单文件需小于 2 GiB。因此大型资源作为 Release 附件提供，代码仓库保持轻量。

## 在另一台电脑恢复

1. 克隆代码仓库，进入 `dsp` 项目根目录。
2. 下载两个 ZIP，解压到项目根目录，保留其中的 `models/` 和 `models_loo/` 目录层级。
3. 在新电脑安装 64 位 Python 3.12，运行 `setup_music_windows.bat`；需要双人分离时再运行 `setup_speakers_windows.bat`。
4. 运行 `run_windows.bat`。

已恢复对应模型时，界面复用本机模型文件。个人录音已在 Git 仓库中，无需另外下载资源包。

校验下载文件：

```powershell
Get-FileHash .\all-models.zip -Algorithm SHA256
Get-FileHash .\training-noise-bank.zip -Algorithm SHA256
```

与 `SHA256SUMS.txt` 中对应文件的值核对后再解压。

## 虚拟环境与后续同步

两套虚拟环境不上传。已开始的环境上传已停止，草稿 Release 中的环境分块和合并脚本已移除。原 `.venv/`、`.venv-speakers/` 保留在本机，Git 仍然忽略它们。

源码和录音通过 Git 提交、推送和拉取。Release 附件是带日期的资源快照，不随 `git pull` 自动更新；模型或训练数据变化后，需要另行生成新的资源备份。每台电脑单独安装 Python 依赖。
