## 1. 这个版本实际新增了什么

“自动带阻滤波器（谱减法）”包含两个不同步骤：带阻/陷波用来压制持续窄带干扰，谱减法用来估计并压制噪声。当前项目已经有经典谱减法，此次新增的是先识别干扰，再决定是否执行带阻，以及相应界面操作。

| 项目 | 合并前的当前项目 | 提供的版本 | 合并后的行为 |
|---|---|---|---|
| 经典谱减法 | 已有，含默认固定带阻 | 已有 | 保留谱减核心 |
| 自动陷波 | 没有 | 检测谱峰及持续性，过滤主频/谐波 | 多尺度验证后按需过滤；未检出只做谱减 |
| 四个频率输入框 | 主要用于设计响应演示 | 手动模式参与带阻 | 手动模式实际使用，错误参数明确拒绝 |
| 自动填频率 | 没有 | 根据当前音频填入 | 使用与自动处理相同的检测，后台执行，只预览 |
| 自动模式二次带阻 | 不适用 | 陷波成功后仍执行默认固定带阻 | 修正：陷波后只做谱减 |
| 方案对比 | 使用默认固定带阻 | 仍使用默认固定带阻 | 与单独⑦按钮使用相同模式和参数快照 |
| 滤波响应 | 四个输入框对应的设计曲线 | 仍可能显示输入框曲线 | 显示本次实际滤波器叠加响应；未陷波时显示 0 dB |
| 运行与导出 | 后台任务及元数据 | 部分处理在主线程 | 沿用当前后台版本隔离，导出记录实际频点和模式 |

## 2. 使用方法

1. 重新启动当前项目，导入语音。
2. 左侧「处理」→「谱减法带阻 / 陷波设置」，默认启用自动陷波。
3. 点击「⑦ 经典谱减法（对比）」：检测持续窄带干扰，有则陷波，再做谱减。完成后弹窗说明实际决策。
4. 点击「检测并填入带阻频率」只检测/预览，填入最强干扰附近的频率，不修改当前音频。
5. 手动处理时取消自动勾选，修改四个频率，满足 `0 < fp1 < fs1 < fs2 < fp2 < 采样率/2` 后再点击⑦。
6. 「⑧ 多方案降噪对比」沿用同一陷波配置，选择经典方案后也显示其实际响应。

`fp1/fp2` 是通带两侧边界，`fs1/fs2` 是阻带边界。自动模式不读取这四个值；它们可用于预览或随后切换到手动模式。

## 3. 合并时修正的问题

本次先移入来版的谱峰突出度、安静/响亮帧持续性判据，再针对实际波形处理修正定位与滤波链路：

- **重复固定带阻**：来版成功陷波后调用默认 `classic_denoise`，会再过滤 1750～1850 Hz。现在明确使用 `bandstop=False` 进入谱减。
- **纯单频的假谐波**：粗 STFT 的频率栅格和旁瓣会让纯 50 Hz 被报告为多条谐波。现在用多帧细谱确认频点，并排除微弱旁瓣和主峰阻带内的邻近假峰。
- **首段静音及工频误定位**：来版只取开头一段做细谱，中心频率搜索还可能跳到别的峰。现在在整段均匀采样最多 128 个完整细谱帧，并用粗谱持续性验证，单频/谐波分别定位。
- **滤波数值稳定性**：中高频 Butterworth 使用二阶节 SOS；低频采用稳定 biquad。手动低频带阻也使用 SOS，减少高阶直接系数形式的不稳定。
- **手动参数被改写或静默跳过**：按原采样率设计并校验自定义阻带；非法顺序或超出 Nyquist 不会偷偷退回默认频率。
- **后台、对比和显示一致性**：模式/频率在任务开始时快照；预览及处理都绑定素材版本；对比和单独运行共享实现；图形使用实际执行的滤波系数。

细谱采用 4096 点窗，补零到 16384 点；16 kHz 下栅格间隔约 0.98 Hz，补零不等于提高独立频率分辨能力。输入先转换到 16 kHz 检测，再在原采样率陷波，输出仍保持原采样率和长度。
