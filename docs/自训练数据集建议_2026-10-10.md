# 自训练数据集建议

核对日期：2026-10-10。已阅读训练、语料划分、噪声加载及下载脚本，并查询下列官方来源。本次是选型与接入调查，未下载数据、未重训或替换模型。

## 项目实际需要

`train_model.py` 训练纯 NumPy 的语音降噪 MLP：默认 16 kHz，干净语音与噪声在线混合，生成 IRM 掩蔽标签，无需转录文本。优先补充多说话人的干净语音，再扩充真实噪声。

`models/runs/20261005_fixed_full/split_manifest.json` 仅记录 5 段、每段 4 秒，总计 20 秒（训练 16 秒，验证 4 秒）。这是该次训练的有效片段规模，不代表所有本地音频总时长。实际 `models/active_model.json` 指向 `models/denoise_mlp.npz`，与 README 所述启用新版不一致。

本地已有办公室、厨房、洗碗机、餐厅、公园、广场、车内、地铁、交通等噪声目录。无需把这些场景全部重新下载。

## 推荐清单

| 优先级 | 数据集及官方入口 | 内容、体量 | 项目用途与接入 | 许可说明 |
|---|---|---|---|---|
| 1 | [AISHELL-1 / OpenSLR 33](https://www.openslr.org/33/) | 400 位普通话说话人；安静室内录音，16 kHz；主压缩包约 15 GB，官网提供中国镜像 | 中文干净参考首选；只从官方训练集抽样起步，dev/test 保留 | 官方页面标注 Apache 2.0，并说明学术使用免费；保留原始许可 |
| 2 | [MS-SNSD](https://github.com/microsoft/MS-SNSD) | 16 kHz WAV；干净语音与环境噪声；仓库分 clean_train、clean_test、noise_train、noise_test | 快速打通语音＋噪声训练；只导入 train 两个目录，test 单独保存 | 数据按原始来源分别授权；仓库代码 MIT 不等于全部音频 MIT |
| 3 | [MUSAN / OpenSLR 17](https://www.openslr.org/17/) | 音乐、语音、噪声；完整压缩包约 11 GB | 优先取 noise 子集；项目已有下载入口 | CC BY 4.0 |
| 4 | [LibriSpeech / OpenSLR 12](https://www.openslr.org/12/) | 英语朗读，16 kHz；train-clean-100 为 100 小时、约 6.3 GB | 补充英文与音色多样性；从 train-clean-100 抽样；dev/test 保留评估 | CC BY 4.0 |
| 5 | [VoiceBank＋DEMAND / Edinburgh](https://datashare.ed.ac.uk/items/6ed35425-bf14-4d2b-93a1-0a4984952757) | 48 kHz 成对干净/带噪音频；28 人训练集 clean 2.32 GB、noisy 2.64 GB；测试 clean 147.18 MB、noisy 162.68 MB | 优先用作固定基准测试；当前训练器没有读取预配对 noisy/clean 的接口。clean_train 可单独用于现有混音训练 | 官方页面提供 End-user Licence，使用时保留并核对该文件 |

后续扩展：[RIRS_NOISES](https://www.openslr.org/28/) 为 16 kHz、约 1.3 GB、Apache 2.0，适合混响增强；RIR 是卷积滤波器，不能直接当加性噪声塞入噪声池。当前混音训练需要额外接入卷积增强后才能利用 RIR。

## 首轮建议

建议先选 AISHELL-1 官方训练集中的 20–50 位说话人，均衡抽取合计 30–60 分钟；搭配已有环境噪声及少量 MUSAN noise。这个规模是针对当前本地 MLP 的起步建议，不是数据集官方配方或效果保证。

保持 16 kHz 单声道，先沿用现有 SNR -5～20 dB、真实噪声概率 0.3 作为对照。后续根据独立测试结果再扩大到数小时；不宜直接把整个大语料库全部载入当前内存式训练器。

## 现有接入方法

以下命令在 `E:\dsp\dsp_py` 中执行；数据目录为示例，需要先下载、解压并整理对应子集。AISHELL 的包内说话人压缩包也需要展开。语料导入器接受文件夹或 zip，不直接解包 tgz。

```powershell
# 先把已抽样的 AISHELL 训练音频放到 datasets\aishell_subset_train
.venv\Scripts\python.exe -X utf8 corpus_tool.py import --from datasets\aishell_subset_train --recursive --dry-run
.venv\Scripts\python.exe -X utf8 corpus_tool.py import --from datasets\aishell_subset_train --recursive
.venv\Scripts\python.exe -X utf8 corpus_tool.py audit

# 可选：现有 MUSAN 下载入口，提取 noise 部分
.venv\Scripts\python.exe -X utf8 download_datasets.py --dataset musan --max-clips 300

# 导入语音会写入 recordings，训练器默认发现该目录的 WAV
# 输出新版本；此示例不自动启用，便于与旧模型比较
.venv\Scripts\python.exe -X utf8 train_model.py --noise-dir models\noise_bank\real --file-noise-ratio 0.3
```

语料导入默认只保留 0.3–30 秒的文件，训练切段不足 1 秒会丢弃；超长音频需事先切段或调整导入参数。保留原始数据、官方划分及说话人映射，不能只保留导入后的扁平 WAV。

## 接入时必须注意的代码限制

1. `core/corpus.py` 按音频内容哈希分组，能隔离相同文件及其切片，但不是按说话人划分。同一个人的不同录音仍可能同时进入训练与验证。严格评估需增加说话人分组，或单独使用官方保留的测试集。
2. `train_model.py` 的训练和验证共用同一个真实噪声池，不能据此证明对未见噪声泛化。独立测试应另留噪声来源/场景；DEMAND 同次录音的不同通道也应放在同一划分。
3. `core/data.py::load_noise_pool` 对每个传入目录递归搜集后排序，只取前 400 个文件、每条前 10 秒。一次指向汇总根目录可能偏向前面几个数据集。应先均衡准备小型噪声目录，或后续改成按场景分层、随机片段采样。
4. `download_datasets.py::download_ms_snsd` 按路径中的 clean/noise 关键字分流，没有排除 test，直接运行会把官方训练和测试素材混入同一池。建议手动只导入 clean_train、单独指定 noise_train，或修复下载器后再用。
5. MS-SNSD 下载器把来源许可写为 MIT，与官方 README 的分来源数据许可说明不符。其语音包含 PTDB-TUG 的 ODbL 与 Edinburgh 条款；噪声包括 CC0 及其他来源许可，应分别保留。
6. 本地 DEMAND 来源记录标为 CC BY 4.0，但 MS-SNSD 官方 README 引用 DEMAND 为 CC BY-SA 3.0。本次 Zenodo 页面访问超时，未完成原始发布许可复核，不能直接沿用本地标注作为确认结论。[DEMAND 原始发布入口](https://zenodo.org/records/1227121)。
