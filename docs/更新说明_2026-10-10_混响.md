# 更新说明：混响与去混响

日期：2026-10-10。

已在左侧新增「音效」页，提供可调房间混响与 WPE 去混响，并接入现有后台任务、处理结果、试听、时域/频谱显示和 WAV 导出。使用已有 NumPy / SciPy，不需要下载模型或安装新依赖。

## 怎么使用

1. 导入或录制音频，打开左侧「音效」。
2. 选择「原信号」或「当前处理结果」。
3. 添加混响时设置衰减时间、湿声比例、预延迟和高频衰减，再点「添加混响」。
4. 去混响时设置强度，再点「去混响」。默认 70%，可以降低以保留更多原声。
5. 使用「试听原信号」「试听处理结果」对比，或「导出处理结果」保存。

添加混响后来源自动切换为「当前处理结果」，可以直接继续去混响。选回「原信号」会重新从导入音频处理，避免不断叠加效果。重新导入音频会清空处理历史；过期后台结果不会覆盖新素材。

## 参数与行为

| 参数 | 范围 | 作用 |
|---|---|---|
| 混响衰减 RT60 | 0.1～5 秒 | 控制尾音包络降低 60 dB 的时间 |
| 湿声比例 | 0～100% | 干声与房间响应输出的混合比例；0% 原样返回 |
| 预延迟 | 0～200 毫秒 | 控制湿声开始前的延迟，另外包含早期反射的延迟 |
| 高频衰减 | 0～100% | 越大，尾音高频越弱 |
| 去混响强度 | 0～100% | 原声与 WPE 输出混合；0% 原样返回 |

混响采用早期反射加指数衰减的扩散尾音，与原来的单次「回声」功能不同。参数固定时结果可复现。

去混响采用延迟加权线性预测 WPE，估计并减弱晚期混响；内部使用 16 kHz STFT、10 阶预测、3 帧预测延迟和 3 次迭代。长文件按最多 8 秒的块处理，重叠 1 秒交叉淡化，限制临时内存并平滑边界。处理结束恢复原采样率和样本数。

参考：[NARA-WPE 算法说明](https://nara-wpe.readthedocs.io/en/latest/)。本项目以 NumPy/SciPy 实现，不依赖 nara-wpe 软件包。

## 适用范围与限制

- 音效页沿用语音工作区的单声道处理方式；算法接口另外支持立体声，并保留声道数。
- 输出与输入等长，超出原文件末尾的新增尾音截断；若要保留整段尾音，可先在素材末尾补静音。
- WPE 主要减弱晚期拖尾，不保证完全恢复干声，也不能代替降噪或消除所有早期反射。过高强度可能削弱人声，建议试听后调整。
- 去混响对静音及不足 0.4 秒的素材原样返回；更长素材在局部预测数据不足时也保留原块。
- 非零效果处理结果超过 0.99 峰值时，会对全部声道统一降低增益。零强度返回原样；现有 WAV 导出仍使用原项目的峰值保护和 16 位 PCM。

## 导出与处理历史

「导出处理结果」生成 WAV 和同名 `.wav.json`。JSON 的 `processing` 数组记录执行顺序及每一步参数，例如「添加混响 → WPE 去混响」。如果来源是降噪后的结果，也会记录上一步算法和模型路径。

处理图的比较对象是本次操作输入：对已混响结果去混响时，显示的是去混响前后，而不是将干声直接与最后结果比较。频谱和高低能量变化仍是观察指标，不作为无参考音质评分。
