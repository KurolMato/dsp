# 更新说明：分离后的逐轨降噪与噪声门

日期：2026-10-10。项目：`E:\dsp\dsp_py`。

已在「双人语音分离」工作区增加「逐轨降噪 / 噪声门」页。两条音轨分别配置，原始分离结果保留；未改变现有音乐人声/伴奏模块或 SepFormer 分离算法，也没有新依赖或新模型下载。

## 使用步骤

1. 先分离双人录音，或打开已有双人分离结果。
2. 切换「逐轨降噪 / 噪声门」，分别设置音轨1和音轨2。
3. 点击「应用后处理（两条音轨）」。设置变化不会实时改动音频，应用后才生成新结果。
4. 点击「听原始1 / 听增强1 / 听原始2 / 听增强2」，或在试听页切换版本。对比按钮会开始播放，暂停/停止就在后处理页。
5. 「导出当前试听」保存当前选择的版本和音量；「导出两路音轨」保存原始、增强两套音频及清单。

每次重新应用都从原始分离音轨计算，不叠加处理之前的增强结果。应用完成后默认试听增强版本；切换版本保留播放位置和音量，正在播放时会暂停重建流再从该位置继续。小窗口中后处理页可滚动。

## 控制项

| 项目 | 默认值 | 作用 |
|---|---|---|
| 启用轻度降噪 | 开启 | 使用已有 GTCRN 增强模型 |
| 降噪强度 | 35% | 原音与 GTCRN 输出混合；0% 原样返回 |
| 启用噪声门 | 关闭 | 在低电平时压低输出，不能识别某个说话人 |
| 门限 | -45 dBFS | 按约20 ms RMS 判断；调高更容易压低弱声，也更容易吞轻声 |
| 压低幅度 | 18 dB | 关门后的底部增益；保留平滑弱声，不硬切为静音 |

界面滑杆范围：降噪 0～100%，门限 -65～-20 dBFS，压低 0～36 dB。噪声门采用3 dB迟滞、8 ms开启、120 ms保持、160 ms释放，以减少开关抖动和突然截断。门限根据原音轨电平计算，不跟随试听音量滑杆。

可先用25～40%降噪，试听后决定是否开启噪声门。模型把残留的另一个人也可能视为语音，因此普通降噪不保证清除串音；噪声门主要帮助目标语音停顿时的弱声，两人同时发声时仍需要更好的分离结果。

## 原音与导出

后处理创建独立的 `results/speakers/时间戳_任务ID/` 目录，包含：

- `original.wav`：混合原音。
- `speaker_1_raw.wav`、`speaker_2_raw.wav`：未增强的原始分离两路。
- `speaker_1_enhanced.wav`、`speaker_2_enhanced.wav`：增强两路。
- `result.json`：模型、原始/增强文件地址、逐轨参数、来源任务和后处理耗时。
- `worker.log`：阶段、进度和错误。

输出保留采样率与长度。参数保存在 `postprocess.tracks` 中，文件清单分别为 `raw_files` 和 `enhanced_files`。再次打开历史会恢复两种版本和应用时的设置；导出试听的 JSON 记录 `audition_version`，避免把原始试听误记为增强输出。

任务在当前基础环境的独立子进程执行，可取消。取消时不保留成功结果标记，原音不受影响。处理错误或参数错误保留上一份结果，旧任务事件不会应用到新任务。
