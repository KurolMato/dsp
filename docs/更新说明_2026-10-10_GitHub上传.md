## 两台电脑使用

1. 另一台电脑安装 64 位 Python 3.12 和 Git。
2. `git clone https://github.com/KurolMato/dsp.git`，进入克隆得到的 `dsp` 目录。
3. 运行 `setup_music_windows.bat`；需要双人分离时再运行 `setup_speakers_windows.bat`。
4. 运行 `run_windows.bat`。音乐和双人分离大模型首次从界面下载，下载后复用本机缓存。
5. 每次编辑前 `git pull --ff-only`；完成后 `git add .`、`git commit -m "修改说明"`、`git push`。

Git 同步提交后的代码，不同步编辑过程、Python 环境、模型下载缓存和个人音频。源码和依赖变更后，必要时重新运行安装脚本。
